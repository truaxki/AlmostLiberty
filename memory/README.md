## 🎯 Project Overview

**Almost Liberty** is a travel recommendation platform that combines real-world travel planning with imaginative exploration of fictional locations. Users can get activity recommendations for places like "New York" or "Narnia" using Google Gemini AI.

### Core Technologies
- **Backend**: Node.js + Express
- **Frontend**: Vanilla HTML/CSS/JavaScript
- **AI**: Google Gemini 1.5-flash
- **Deployment**: Vercel
- **Data**: Hybrid approach (predefined JSON + AI generation)

### Key Features
- Location-agnostic recommendations (real + fictional)
- "Spin the Globe" random destination selector
- Dual data strategy for optimal performance
- Caching system for AI responses
- Space-themed UI with cosmos imagery
